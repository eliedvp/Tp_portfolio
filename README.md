# Portfolio en une page — HTML

Exercice réalisé pendant la formation GoMyCode : structurer une page de portfolio personnel en HTML.

## Ce que contient la page

- Un menu de navigation par ancres (Accueil, À propos, Travail, CV, Contact).
- **À propos** : courte présentation.
- **Mes réalisations** : deux projets réalisés avec WordPress (un site e-commerce et un site vitrine présenté par une vidéo, `videos/p1.mp4`).
- **Mon CV** : lien de téléchargement.
- **Contact** et pied de page.

## Notions travaillées

- Balises sémantiques HTML5 (`header`, `nav`, `section`, `article`, `footer`)
- Navigation interne par ancres (`href="#section"`)
- Listes ordonnées, liens, intégration d'une vidéo (`<video>`)

## Fichiers

- `Tp_portfolio.html` : la page.
- `styles.css` : feuille de style (variables CSS, animations). Elle n'est pas encore reliée à la page : il faut ajouter `<link rel="stylesheet" href="styles.css">` dans le `<head>` pour l'appliquer.

## Stack

HTML5, CSS3.

## Lancer le projet

Ouvrir `Tp_portfolio.html` dans un navigateur.
